Fastcloud — нативный SoundCloud-клиент на Rust: egui/eframe 0.36 (glow), rodio/cpal, reqwest+tokio, тот же стек, что у Fastpotify. Next.js-проект в репо удаляется, в корне — Cargo.toml + src/.
Вход: OAuth 2.1 + PKCE через secure.soundcloud.com, loopback-редирект 127.0.0.1:41317/callback, токены в keyring, авто-refresh. Ключи приложения — при сборке (FASTCLOUD_CLIENT_ID/SECRET) или в Settings; без ключей работает --demo.
API-слой поверх официального api.soundcloud.com: лайки, плейлисты, подписки, лента, недавнее, поиск (треки/плейлисты/люди), страницы трека/плейлиста/юзера, репосты, комментарии, related, создание/редактирование плейлистов (PUT с полным списком треков), пагинация linked_partitioning, обработка 429.
Плеер: GET /tracks/{urn}/streams → собственный HLS-загрузчик → symphonia (AAC/MP3) → 10-полосный EQ → лимитер → cpal. Очередь, shuffle/repeat, seek, gapless-prefetch, resume последней сессии, дисковый кеш аудио, fallback на 30-сек preview.
Десктоп: трей (tray-icon/ksni), медиа-клавиши (souvlaki/MPRIS), один инстанс + CLI (fastcloud next|toggle|volume…), хоткеи для всех действий, темы light/dark/system, акцент от обложки, drag&drop в плейлисты.
Упаковка/CI: GitHub Actions (fmt/clippy/test/build на 3 ОС, релизы .app/.exe/AppImage), PKGBUILD, Homebrew cask, Flatpak, Inno Setup, .desktop, README, MIT.
Отличия от Fastpotify из-за API SoundCloud: нет аналога Spotify Connect (только локальное воспроизведение), нет альбомов/подкастов/lyrics; для ключей API у разработчика нужен SoundCloud Artist Pro. Проверка здесь: cargo build/test + скриншоты через Xvfb в --demo.
