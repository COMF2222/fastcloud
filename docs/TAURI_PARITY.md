# Перенос egui → React/Tauri

Рабочий список для проверки полной функциональной совместимости. Отметка означает наличие реализации в `desktop/`, а не проверку на живом аккаунте.

## Перенесено

- [x] Подключение SoundCloud и сохранённая авторизация, личный профиль.
- [x] Воспроизведение, очередь, история, лайки, репосты, поиск, страницы треков, авторов и плейлистов.
- [x] Создание и редактирование плейлистов, массовый выбор треков и действия с ним.
- [x] Лента с треками и плейлистами, переключатель репостов.
- [x] Навигация по результатам поиска стрелками и воспроизведение через Enter.
- [x] Комментарии, подписки, загрузка и редактирование своих треков, витрина.
- [x] Импорт из Яндекс Музыки, эквалайзер и пресеты, аудиокэш.
- [x] Быстрый доступ, локальные обои и пользовательский шрифт.
- [x] Локальная история открытых ссылок (`inbox`).
- [x] Мини-плеер, мультимедийные клавиши, трей, ссылки `fastcloud:` и базовые горячие клавиши.
- [x] Фильтрация разделов медиатеки и переключение списка/сетки.
- [x] Классический мини-плеер со стандартным и пользовательскими `.wsz` скинами, масштабом 1–4×, windowshade, панелями EQ и очереди, их shade-режимами и изменением числа строк очереди.
- [x] Перетаскивание `.wsz`, шрифтов и аудиофайлов в окно; аудио подставляется в форму загрузки.
- [x] Спектр и осциллограф на реальном аудиосигнале в классическом мини-плеере, переключение режимов.
- [x] Пять основных вкладок, переключатель языка и сворачивание боковой панели; быстрый доступ находится в боковой панели и сохраняет обложки в узком режиме.
- [x] Настройки с отдельными разделами: общее, оформление, звук, интеграции, хранилище, аккаунт.
- [x] Старый встроенный Fastcloud Classic в мини-плеере вместо исходного Fastpotify.
- [x] Постоянная офлайн-библиотека: загрузка лайков целиком или по одному, список, удаление, локальное воспроизведение HLS без обращения к API.
- [x] Прокси SoundCloud CDN для обложек с возвратом к исходному URL, исправленные заливка полосы перемотки и слой пользовательского фона.
- [x] Собственный профиль с аватаром и разделами треков, альбомов, плейлистов, лайков и репостов: данные владельца читаются из `/me`, содержимое плейлистов может подставляться из ответа деталей. Чекбоксы в строках треков убраны.
- [x] Классический мини-плеер: высота очереди меняется перетаскиванием нижнего угла, доступны пресеты Flat/Bass/Vocals/Bright и сохранение EQ для трека.
- [x] Английские подписи и сообщения новой React-оболочки, включая справку по клавишам, подтверждения удаления и режим предпросмотра.
- [x] На локально сохранённой сессии проверены `/me`, первая страница лайков и сохранённых плейлистов; оба маршрута собственных плейлистов (`/me/playlists` и `/users/:id/playlists`) вернули пустой список.
- [x] Приватный Windows-установщик включает квантованные CLAP-модели и облегчённый CPU-воркер; после установки проверены текстовый и аудио-вектор размерности 512.
- [x] Поиск текста повторяет временные 503/429 LRCLIB с учётом `Retry-After`, отличает недоступность источника от отсутствия текста и предлагает повторить запрос.

## Ещё требуется

- [ ] Довести оформление очереди до точных спрайтов `.wsz` в пользовательских скинах.
- [ ] Зарегистрировать собственное Discord-приложение Fastcloud и встроить его Application ID в сборку. Без этого Discord Rich Presence требует ручного ID.
- [ ] Проверить загрузку обложек и полные офлайн-треки на живом аккаунте, включая отключённую сеть.
- [ ] Проверка каждого личного раздела и операций записи на реальном авторизованном аккаунте.
- [ ] Проверка установочных пакетов и запуска на macOS и Linux.

Windows установщик и portable ZIP собираются локально. Публикация релиза должна идти через проверенный CI после закрытия функциональных пунктов и проверки на живом аккаунте.
