# Скриншоты для README

Основные скриншоты уже добавлены из установленной версии Fastcloud, предоставленной владельцем.
Главная — большой скрин сразу после описания; большой плеер — ниже возможностей;
мини-плеер — отдельный компактный кадр. Каталог, поиск и настройки собраны
в раскрывающиеся блоки.

## Как снять

- Для первых трёх используй одинаковый размер окна, например 1600×900.
  На экране поменьше подойдёт 1280×800 — важнее читаемость и одинаковые размеры.
- Сохраняй в PNG. Избегай повторного сохранения через мессенджер с сжатием.
- Выбери одну спокойную тему: достаточно контраста для текста, фон не отвлекает.
- Закрой меню и всплывающие подсказки, убери указатель с кнопок.
- Снимай окно приложения целиком, без браузера, терминала и панели задач.
  Для мини-плеера оставь только само окно с небольшим полем вокруг.
- На главной оставь живую библиотеку с обложками; не используй пустые разделы.
- В настройках не открывай данные аккаунта, токены и административные списки.

Видео и GIF для первого оформления не нужны. Все девять полученных изображений
сохранены без изменений и включены в обе языковые версии с описательным alt.
Дополнительные настройки: `surfaces.png`, `background.png` и
`performance-fonts.png` — в раскрывающемся блоке. Чтобы обновить оформление
README, можно заменить соответствующие файлы в `assets/screenshots/`.
